# Evidence Claims Register

Each row is one factual claim the research package relies on.

- **Label:** evidence classification (DOCUMENTED, CORROBORATED, REGIONALLY SPECIFIC, DISPUTED, INFERRED, SPECULATIVE, FICTIONAL, NOT FOUND, NON-IGBO COMPARATIVE).
- **Verification status:** what was done this session. Values:
  - **RETRIEVED** — the source's title, authors and key text were seen in a search result this session.
  - **SNIPPET (earlier)** — seen in an earlier search in this working session; summarised in earlier notes.
  - **SECONDARY** — the claim is only reported through another source; the original was not seen.
  - **NOT RETRIEVED** — from prior knowledge or earlier notes; not checked this session.
  - **UNSOURCED** — the package states it without a citation in the package.
- **Questions:** the Field of Cloth consultant questions in `05_Consultant_Response_Sheet.csv` that bear on this claim.
