# Source Verification Log

**Purpose:** record, for each source code used in `RESEARCH/`, what kind of check was done and what remains. A consultant or reviewer can use this to decide what to trust.

**Status key**
- **RETRIEVED** — title, authors, journal and key text were seen in a search result in this working session (2026-11-17 verification pass or earlier sessions).
- **SNIPPET (earlier)** — seen in an earlier search in this working session; summarised in earlier notes.
- **SECONDARY** — the work is known only through another source's citation or quotation.
- **NOT RETRIEVED** — cited from prior knowledge or earlier notes. Not checked this session. Do not cite externally until verified.
- **WEB LEAD (T4)** — blog, news, commercial or community site. Used only as a lead.
