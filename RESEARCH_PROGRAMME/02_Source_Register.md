# 02 — Source Register (RP- codes)

Working date 2026-11-17. Pack codes (`OKE22`, `BAS21`, `IGI25`, `SHA70`, `AMA87`, etc.) refer to `RESEARCH/G_Bibliography.md`. Where a pack code exists, it is given in the "Pack" column.

**Access key:** FETCHED = page text read in this session · SNIPPET = search-result text or abstract only · CITED = named in another source, not accessed · NOT ACCESSED = identified only.
**Tier:** T1 primary record · T2 peer-reviewed / university press · T3 reputable institution or journal, status unconfirmed · T4 lead only, never used for historical conclusions.
**Limits:** "Author not captured" means the snippet did not show it; verify before citing externally.
