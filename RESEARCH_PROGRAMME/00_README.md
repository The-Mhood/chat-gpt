## Method and limits (read before using any claim)

- Desk research only: web search results, abstracts, and a small number of fetched pages. Most sources were read as **search snippets or abstracts**, not full text. Each source's access status is recorded in file 02.
- **Page numbers** are given only where a source reported them. None were verified in this session unless stated.
- **Tiers** follow deliverable G: T1 primary record; T2 peer-reviewed or university-press scholarship; T3 reputable institution, archive or journal whose peer-review status was not confirmed; T4 lead only (blog, news, wiki, commercial, aggregator). T4 is never used for a historical conclusion.
- **Evidence labels** follow the assignment: DOCUMENTED, CORROBORATED, REGIONALLY SPECIFIC, DISPUTED, INFERRED, SPECULATIVE, FICTIONAL. A label describes the strength of the evidence, not whether a visual choice is acceptable.
- **Igbo diversity:** every cultural claim names its community or region where the source does. Nothing here generalises one community's practice to all Igbo.
- **No backward projection:** colonial-era accounts (Basden 1921, Talbot 1926) describe their own period and are not used as pre-colonial evidence without a caveat.
- **Absence is not proof.** Where no documented example was found, the file says so and does not say the practice never existed.
