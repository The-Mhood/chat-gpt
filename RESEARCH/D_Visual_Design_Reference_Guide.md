# Deliverable D — Visual Design Reference Guide (for the Visual Agent)
THE DISOBEDIENT DAUGHTER · Pre-colonial Igbo-inspired visual language · Working date 2026-11-17

> **How to use this guide.** Every item has a status:
> - **SAFE** — may be used as a general visual reference, with the regional label noted in production notes.
> - **QUALIFY** — use only with the stated region, period and framing. Do not generalise.
> - **CONSULT** — do not reproduce or adapt without a living Igbo cultural consultant's sign-off.
> - **AVOID** — do not use (evidence shows it is a misleading or non-Igbo reference).
>
> Nothing in this guide authorises artwork. Items marked SAFE are research-backed visual references only.

## 10. Rules of thumb for the Visual Agent

1. **Name the region and period** in every production note for any SAFE or QUALIFY item.
2. **Do not combine** SAFE items into a composition that reads as a single "Igbo funeral". Combination is itself a claim.
3. **Do not invent** motifs, colours, patterns or objects and attribute them to Igbo culture.
4. **Do not use** a pole-and-cloth structure as an Igbo funerary image.
5. **Do not use** any CONSULT item until a custodian has signed off.
6. **Carry the fictional disclaimer** into every use if the imagery is fictional.
7. **Verify before use:** any item drawn from a [VERIFY] source needs confirmation first.
